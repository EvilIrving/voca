# 元素表（Parley 真机实测）

取样环境：vivo `V2454DA`（`PD2454`），序列号 `ANDROID_SERIAL`，屏幕分辨率 `1080×2376`，像素密度 `density 480`（1dp ≈ 3px）。

Compose 声明式界面中的坐标（bounds）会因系统字体缩放、动态状态和列表滚动而发生位移，下表提供真机实测定位参考与标准命名标识。执行操作时建议通过 `.agents/skills/android-device-testing/scripts/android-drive.sh el` 获取当前实时坐标，依靠 `text` 或 `content-desc` 进行稳定识别。

## 3. 触控收音面板（`app:收音中`）

判定特征：屏幕显示 `松手发送` 或 `上滑取消`。

| 元素 | 说明 |
| --- | --- |
| 状态提示 | 显示 `松手发送`（常规录音状态）或 `上滑取消`（滑动位移超出阈值） |
| 声波柱阵列 | 实时动态波形渲染（欧拉滤波平滑） |
| 拾音圆钮 | 居中陶土色麦克风拾音指示 |
| 计时显示 | 实时记录本次发言时长（如 `00:03`） |
| 顶部把手 | 抽屉把手微件 |

## 4. 半屏评测分析抽屉（`app:评测抽屉`）

判定特征：屏幕包含 `本轮评测` 标题。

| 区域 | 元素标识 / 文字 | 作用说明 |
| --- | --- | --- |
| 顶栏 | `本轮评测` | 评测抽屉标题 |
| 顶栏 | `关闭`（右上角叉号） | 关闭评测抽屉并返回对话列表 |
| 原文复听 | 原文卡片 + `复听原文`（播放图标） | 重新播放用户本轮录音音频 |
| 评分栏 | `发音`（分值与评价） | 展示音素级发音综合得分 |
| 评分栏 | `语法`（分值与评价） | 展示语法与用词准确性得分 |
| 发音建议 | 音素词条（WordChip） | 标明存在发音偏误的具体词汇与国际音标 |
| 母语者表达 | 档位切换（如 `地道日常` / `专业地道`） | 切换不同语体风格的母语者改写示范 |
| 母语者表达 | 改写卡片操作项 | 包含 `播放改写`、`翻译`、`收藏` |
| 底部操作 | `收进生词本` | 将改写中的重点表达或生词加入本地生词库 |
| 底部操作 | `继续对话` | 退出评测抽屉继续下一轮口语交流 |

## 5. 生词库界面（`app:生词库`）

判定特征：顶部包含 `生词库` 标题，且出现 `搜索词或音标` 搜索框。

| 区域 | 元素标识 / 文字 | 作用说明 |
| --- | --- | --- |
| 顶栏 | `生词库` | 页面主标题 |
| 顶栏 | `关闭`（右上角叉号） | 关闭生词库返回对话界面 |
| 搜索框 | `搜索词或音标` | 过滤检索本地收录的词汇与短语 |
| 分组筛选 | `今天 24` / `待复习 9` / `全部 15` | 按学习进度与时间维度筛选词条 |
| 生词卡片 | 单词标题（如 `slept badly`, `crave`） | 目标词汇或地道短语展示 |
| 生词卡片 | 音标与释义 | 国际音标、中文释义与母语例句 |
| 生词卡片 | `复现 N 次` | 统计该词汇在日常对话中的出现频次 |

判定特征：顶部包含 `配置中心` 标题，且包含 `实时对话`、`识别与分析`、`角色提示词`、`连接自检` 等模块。

| 区域 | 元素标识 / 文字 | 作用说明 |
| --- | --- | --- |
| 顶栏 | `配置中心` | 页面主标题 |
