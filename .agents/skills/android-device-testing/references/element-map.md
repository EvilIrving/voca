# 元素表（Parley 真机实测）

取样环境：vivo `V2454DA`（`PD2454`），序列号见 `$PARLEY_DEV`（WLAN 调试广播名同样带序列号，脚本按它匹配），屏幕分辨率 `1080×2376`，像素密度 `density 480`（1dp ≈ 3px）。

Compose 声明式界面中的坐标（bounds）会因系统字体缩放、动态状态和列表滚动而发生位移，下表提供真机实测定位参考与标准命名标识。执行操作时建议通过 `.agents/skills/android-device-testing/scripts/android-drive.sh el` 获取当前实时坐标，依靠 `text` 或 `content-desc` 进行稳定识别。

## 1. 主对话界面（`app:主对话`）

判定特征：包含 `按住说话` 或 `点击输入或长按说点什么`，或者顶栏包含 `生词库`、`会话记录`。

| 区域 | 元素标识 / 文字 | 实测中心点 | 作用说明 |
| --- | --- | --- | --- |
| 顶栏左侧 | `新会话`（气泡加号图标） | `378,189` | 对话进行中才出现；点一下收掉这一段并开新的一段。空着的新会话与历史回看都不放这一枚，回看时左上角换成返回箭头 |
| 顶栏中段 | 会话名（新会话不显示，回看时显示） | `558,189` | 只读文字，界面上没有箭头；那一小块仍收点击，点开左侧会话抽屉 |
| 顶栏右侧 | `生词库`（图标） | `757,189` | 靠最右；打开全屏生词库，右上角角标 `17` 这类数字是今日新增条数 |
| 对话气泡 | Echo 智能体气泡 | 列表自上而下 | 母语者回应文本，长按开消息菜单 |
| 对话气泡 | User 用户气泡 | 列表靠右 | 用户口语输入文本，下方是评分徽标 |
| 用户评分 | `查看评测` / 发音与语法双分 | 紧随用户气泡下方 | 点开半屏评测抽屉 |
| 底栏左侧 | `点击输入或长按说点什么`（胶囊空态） | `453,2226`（胶囊 `[21,2154][885,2298]`） | 点一下进草稿输入；长按开始收音 |
| 底栏右侧 | `按住说话`（麦克风圆钮） | `987,2226`（可交互区 `[915,2154][1059,2298]`） | 长按开始收音，左滑作废、上滑锁定 |

## 2. 会话抽屉（左侧推入）

判定特征：屏幕左侧出现 `会话` 标题与 `新会话` 胶囊，主对话被向右推开并缩小。入口两条：底栏以上的任意位置向右横滑，或点顶栏那段会话名（界面上看不出可点）。

| 元素 | 实测中心点 | 作用说明 |
| --- | --- | --- |
| `会话`（标题） | `380,189` | 抽屉标题，与检索同一行 |
| `搜索会话`（图标） | `778,189` | 把标题这一行换成搜索框，按名字过滤会话 |
| `新会话` | `282,357` | 52 高的胶囊，收起抽屉并开新一段 |
| 历史会话行 | 按 `今天`、`7天内`、`更早` 分组 | 点一下切到那段会话的只读回看 |
| 当前会话行右端 | `会话操作`（更多图标） | 行尾跟随那一行 | 点开重命名、批量选择与删除3 项菜单，与长按这一行同一份 |
| `设置`（图标） | `766,2220` | 抽屉右下角，打开设置 |
| 卡片那一条 | 屏幕右侧露出的窄条 | 点一下收起抽屉；朝左拖也收起 |
| 抽屉内部 | 空的会话区 | 朝左拖也能收起，不必从卡片起手 |

横滑那层挂在没被变换的根层上，抽屉与卡片都是它的孩子，指针坐标就是屏幕坐标；它只在横滑判定成立后才收事件，底栏那条 96dp 的带子整块让给录音。抽屉收起时不挂任何整屏遮罩，顶栏与输入条照常可点——之前那版把遮罩无条件挂在最上层，整屏按压全被吃掉，界面看着完全没反应，这是排查输入失灵时第一个要看的地方。

## 3. 收音中的输入条（`app:收音中`）

判定特征：输入条左端出现红点与 `0:04,6` 这类计时，中间是 `滑动以取消`。

| 元素 | 说明 |
| --- | --- |
| `滑动以取消` | 按住但未滑到作废线；左滑越过一半后换成 `松手取消` |
| 计时 | `分:秒,十分位`，随录音累加 |
| `取消` | 锁定态中间的可点按钮，点一下作废这一轮 |
| `暂停收音` / `继续收音` | 圆钮上方浮出的三十六圆钮，锁定后才会淡入 |
| `丢掉这段录音` | 暂停态胶囊左端的垃圾桶 |
| 深色时间轴 | 暂停态中间 236×32，左侧 24 的陶土播放键，进度按真实录音推进 |

左滑作废与上滑锁定都在这条带子上判：可走距离 min(屏宽×0.35, 140)，滑满当刻就地作废、不用抬手，抬手时进度低于 0.45 也作废；上滑九十六且进度不低于七成锁进锁定态；锁定后圆钮上方 40 的暂停键、暂停后 36 的继续键，底边都离胶囊顶 8；作废一律先播垃圾桶动效再收。

## 4. 半屏评测分析抽屉（`app:评测抽屉`）

判定特征：屏幕包含 `本轮评测` 标题。

| 区域 | 元素标识 / 文字 | 作用说明 |
| --- | --- | --- |
| 顶栏 | `本轮评测` | 评测抽屉标题 |
| 顶栏 | `关闭`（右上角叉号） | 关闭评测抽屉并返回对话列表 |
| 原文复听 | 原文卡片 + `复听原文`（播放图标） | 重新播放用户本轮录音音频 |
| 评分栏 | `发音`（分值与评价） | 展示音素级发音综合得分 |
| 评分栏 | `语法`（分值与评价） | 展示语法与用词准确性得分 |
| 发音建议 | 音素词条（WordChip） | 标明存在发音偏误的具体词汇与国际音标 |
| 母语者表达 | 档位切换（如 `地道日常` / `专业地道`） | 切换不同语体风格的母语者改写示范 |
| 母语者表达 | 改写卡片操作项 | 包含 `播放改写`、`翻译`、`收藏` |
| 底部操作 | `收进生词本` | 将改写中的重点表达或生词加入本地生词库 |
| 底部操作 | `继续对话` | 退出评测抽屉继续下一轮口语交流 |
